# S07 联系方式挖掘

## 目标
为每家公司找到公开的商务联系方式和决策人信息，每一项都附上来源 URL 和查看日期，交给 S08 第二轮核验。

## 输入
通过 S08 第一轮的公司（或用户提供的名单）、S05 的决策人候选、run_config、线索总库。

## 步骤
1. 官网逐页查找（每家最多 run_config 规定的页数）：
   - 首页页脚、Contact / Contact Us；
   - About / Our Story / Team / Leadership；
   - Wholesale / Partners / Stockists / Distributors / Retailers；
   - Press / Media；
   - Privacy Policy、Terms（常有法定名称、地址和邮箱）；
   - 德语区网站的 Impressum、法语网站的 Mentions légales（依法列出负责人、邮箱、电话）。
2. 搜索引擎补充：
   - `"@公司域名"` 查找公开出现过的该域名邮箱；
   - `site:公司域名 email OR contact`；
   - `"品牌名" founder OR CEO`，查找新闻稿、播客、展会名录中的人名。
3. 谷歌地图、Facebook 主页 About、Instagram / TikTok 商业主页简介：查找电话、邮箱、WhatsApp。
4. 按字段记录：

| 字段 | 记录要求 |
|---|---|
| 公司名称 | 法定名称（及来源）；品牌名另记 |
| 网站 | 当天打开后的最终网址（跟随跳转） |
| 公司邮箱 | 优先 sales@、wholesale@、partnerships@，其次 info@、hello@；排除 noreply、privacy@（仅限隐私事务）、网站服务商或代理公司的邮箱 |
| 联系人 | 姓名、职位、主页 URL；小公司优先创始人，中型公司优先产品开发、采购或运营负责人；最多记录 2 人 |
| 联系人邮箱 | 只记录在页面上真实出现的地址；不按姓名规则推测 |
| 电话 | 国际格式（+国家码）；注明总机、门店或对方公开的手机号 |
| WhatsApp | 只记录明确标注为 WhatsApp 的号码（wa.me 链接、WhatsApp 图标、商家信息中的 WhatsApp 字段），写成 https://wa.me/号码 |
| LinkedIn / 社媒 | 公司页和联系人主页链接 |
| 地址 | 办公或经营地址；注册代理人（Registered Agent）地址不算 |

5. 每个字段写明：值｜来源 URL｜来源类型（官网 / 地图 / 商业主页 / 第三方页面 / 用户已有账号的联系人数据库）｜查看日期｜页面上的原文片段。
6. 找不到的字段写“—”，并写明已经查过哪些地方。
7. 交给 S08 第二轮核验。

## 规则
- 不推测邮箱；不用任何方式测试邮箱、电话或 WhatsApp。
- 不提交表单、不注册账号、不订阅邮件来获取联系方式。
- 只收集商务信息，不收集私人住址、私人社媒、家庭信息，以及没有公开用于业务的个人手机号。
- 需要登录或付费才能看到的联系方式，不绕过；用户已有账号的联系人数据库，只有在用户明确提供或授权时使用。
