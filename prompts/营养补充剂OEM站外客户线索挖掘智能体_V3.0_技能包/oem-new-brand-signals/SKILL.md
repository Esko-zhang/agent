# S06 新品牌早期信号

## 目标
在品牌上市前后找到它们，并找到品牌背后的经营主体和官网。

## 输入
S01 的任务（商标检索的日期区间和关键词、目标展会、众筹平台）、线索总库。

## 步骤
1. 美国商标：在 USPTO 商标检索中筛选第 5 类，商品描述含 dietary supplements、nutritional supplements、vitamin gummies、protein powder、sports nutrition 等，申请日期在最近 30–90 天内。记录：商标名、申请号、申请日、申请人名称和类型、所在州或国家、商品描述、状态。
2. 申请人是公司的，搜索它的官网和社媒。申请人是个人的，只查找与该品牌相关的公开业务渠道（品牌官网、品牌社媒）。商标记录中的代理律所信息不作为客户联系方式。找不到经营渠道的放入观察池，30 天后再查。
3. 展会：获取目标展会公开的展商名单，筛出补充剂品牌方（排除原料商和同行），记录展位号和展会日期。
4. 众筹和新品发布：在 Kickstarter、Indiegogo、Product Hunt 搜索补充剂项目，记录项目方、进度、预计发货时间。
5. 次市场：用同样的方法检索 UKIPO、EUIPO 的第 5 类新申请。
6. 对照线索总库去重后，交给 S08 做第一轮背调。

## 输出
新品牌候选表：品牌｜信号类型｜日期｜来源 URL 或申请号｜申请人或公司｜官网和社媒｜所处阶段（申请中 / 预售 / 已上线）。

## 规则
商标信息只能说明对方“可能在筹备品牌”，不能写成“正在找工厂”。
