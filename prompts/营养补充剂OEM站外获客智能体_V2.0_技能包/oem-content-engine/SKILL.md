# S14 内容获客引擎

## 目标
持续为独立站和社媒生产买家会搜、愿意看、能带来询盘的内容，建立集客渠道。所有内容都由人工审核后发布。

## 输入
产品卡和可公开的事实、工厂照片和视频素材清单、S13 的询盘来源统计、目标关键词列表、竞品内容（只作参考，不抄袭）。

## 步骤
1. 关键词规划（每月一次）：按剂型和买家所处的阶段整理关键词簇。
   - 找工厂：private label [剂型] manufacturer、custom [成分] gummies manufacturer、supplement manufacturer low MOQ；
   - 做决策：gummy vs capsule cost、supplement MOQ explained、how long does supplement manufacturing take；
   - 刚起步：how to start a supplement brand、supplement label requirements（只写一般性说明，并提示以法规原文和专业意见为准）。
   每个剂型规划 1 个支柱页 + 4–6 篇支撑文章。
2. SEO 文章（每周 2 篇，每篇 1,200–1,800 词）：开头先给出直接答案；用工厂的真实数据（打样周期、MOQ 区间、工艺步骤、检测项目）；配上 FAQ；结尾链接到对应的剂型页和询盘表单。同时写好标题、meta 描述、内部链接建议和配图需求。
3. LinkedIn（每周 3 条）：工厂实拍的故事、剂型知识、打样过程、对行业趋势的看法。每条 150–250 词，讲一个观点，提一个问题。
4. 短视频脚本（每周 1–2 个，用于 YouTube Shorts、TikTok、Instagram Reels）：30–60 秒，写镜头清单和字幕，例如“软糖从配料到装瓶”。
5. 获客素材：每季度更新一次“补充剂品牌上市工具包” PDF（剂型对比、MOQ 表、打样流程、时间线、标签清单）。
6. 合规自检：不写疾病功效；不写“FDA approved”；证书和数据与产品卡一致；客户案例要获得许可。
7. 月度复盘：根据 S13 的询盘来源统计，找出带来询盘的页面，加强同类内容；连续 3 个月没有带来流量或询盘的主题，停止继续扩写。

## 输出
内容日历、文章草稿（含 SEO 要素）、社媒帖子、视频脚本、待拍摄素材清单。保存到 05_Content/，状态设为“待审核”。
