# S08 企业背调与联系人补全

## 目标
对每家候选公司回答四个问题：它是谁（主体）？它会不会采购补充剂 OEM（类型和证据）？该联系谁？用什么方式联系（来源和验证状态）？

## 输入
S03–S07 的候选、S13 的询盘；可用的工具（浏览器、Accio 背调类技能、LinkedIn 连接器，以及已授权的邮箱查找 / 验证工具）；台账、禁联表、市场规则卡。

## 步骤
1. 核实官网：看 About、Contact、Terms / Privacy 和产品页。记录法定名称、品牌名、地址、国家或州、产品线（剂型 / 成分）、是否是自有品牌、成立时间或经营迹象（最近的更新、新品）。
2. 必要时查官方的公司登记（例如美国各州的公司查询系统），确认法定名称和存续状态。不能凭域名后缀或网站货币判断主体所在国。
3. 判断客户类型（T1–T5 / CN_SELLER / 排除）；一家公司有多种角色的，全部标注。排除同行 OEM、原料商和服务商。
4. 汇总外包 / 进口证据（标签、进口记录、对方的公开说明）和时机信号，写明来源。
5. 决策人：使用 S06 的结果，或用 Accio 的领英 / 背调技能补充。小公司找创始人，中型公司找产品开发、采购或运营负责人。
6. 联系方式：
   - 优先顺序：官网公布的决策人邮箱 > 查找工具给出且验证为 VALID 的决策人邮箱 > 官网公布的业务邮箱（partnerships@、sales@、info@）> 官网表单 > LinkedIn。
   - 按姓名规则推测的邮箱，只有验证结果为 VALID 才能使用；RISKY 标记为人工审核；INVALID 丢弃。没有验证工具时，推测的邮箱一律不用。
   - 每个邮箱都记录来源 URL 或工具名、验证结果和日期。
7. 按市场规则卡判断 market_rule（PASS / REVIEW / BLOCK）并附理由。联系人是个体经营者，或位于需要事先同意的市场时，设为 REVIEW。
8. 查禁联表和现有客户名单，命中就标为 BLOCK 并说明。
9. 交给 S09 评分。

## 输出
企业身份卡（事实｜来源｜日期）、客户类型、证据摘要、决策人表、联系方式表（来源和验证状态）、market_rule、待补的信息。

## 质量标准
“公司存在”、“邮箱存在”、“邮箱能送达”、“允许营销”这四件事要分开判断；没有确认的事项不能用措辞掩盖。
